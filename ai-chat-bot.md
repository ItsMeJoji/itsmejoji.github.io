# AI Chat Bot

This tool lets you run an instance that will transcribe your speech, pass it to ChatGPT, and return the response as a recording. There is OBS integration to have images move when the response is read as well.

## Usage

See the [Repository](https://github.com/ItsMeJoji/AI-Chat-Bot) for full information on requirements and installation.

## Future Features
